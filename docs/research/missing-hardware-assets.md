## Reproducible original-asset intake

`scripts/fetch-sketchfab.mjs` uses only the official download API with an explicitly provided `SKETCHFAB_TOKEN`. It validates UUID/output names, refuses existing output paths, requires downloadable CC0 or CC Attribution assets, rejects advertising-card triangle counts and unsafe archive paths, records original provenance, and routes new models through the corrected PNG/Meshopt → KTX2/full-mip pipeline. It does not harvest browser sessions or private viewer payloads.

For an original GLB already acquired under suitable rights, `scripts/ktx-models.mjs input.glb public/models/new-model.glb` performs the texture-only conversion. Set `TOKTX` to Khronos toktx 4.4.2 and `MOK_ASSET_TOOLS` to a package directory containing Sharp 0.34.5. `scripts/optimize-model.sh` first performs Meshopt and 2K PNG preparation when raw geometry also needs optimization. Audit reports go to `docs/research/assets/`.

After acquisition, verify actual manufacturer dimensions, screen mask and UV orientation, authored finish materials, lid rest pose and camera/port geometry. Add a distinct `DeviceSpec` only after these checks; source names are not a substitute for geometry inspection. Run glTF Validator, model/lid tests and visual closeups before exposing it in the picker. This intake workflow is implemented; the missing detailed hardware remains outstanding.
